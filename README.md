# Nano Coins

Nano Coins is a gamified rewards platform designed to let users earn coins through games, tasks, and other activities.

##  Live Demo

https://nanocoins.lovable.app/

## ✨ Features

- User authentication
- Gamified rewards system
- Games and earning activities
- Coin balance and progress tracking
- User dashboard
- Rewards and withdrawal features
- Responsive mobile-friendly interface
- Admin management features

## 🛠️ Technologies

- React
- TypeScript
- Tailwind CSS
- Supabase
- Git/GitHub
- Lovable

## 📱 Responsive Design

The application is designed to work across mobile, tablet, and desktop screen sizes.
